Data Usage and Citation Policy

All resources contained in this repository (ResQ-UAV), including but not limited to the gt and corrupted image sequences, annotations files, and the integrated mmdetection codebase, are released strictly for academic research and non-commercial purposes.

If you utilize any part of this dataset (images, labels, or code framework) in your research, publications, or projects, you are required to acknowledge the source and cite our corresponding paper. Proper citation supports the sustainability of this project and facilitates reproducibility within the community.

Thank you
